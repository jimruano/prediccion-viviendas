# Predicción de precio de viviendas (CRISP-DM)
1. `pip install -r requirements.txt`
2. `python train.py`   (opcional: ya incluye `models/` entrenados; regenera modelos, métricas y figuras)
3. `streamlit run app.py`
Archivos: `features.py` (preparación + feature engineering), `train.py` (modelado/evaluación), `app.py` (despliegue), `data/train.csv`.
